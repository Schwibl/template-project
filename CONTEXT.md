# Context

Short names. The rule text lives in the linked file.

- **Impact** — the opening of a pull request, handoff, or audit: what the user experienced before and after. See `docs/workflow/impact.md`.
- **Tech-lead** — the PM bot that squash-merges when the merge gate passes. See `docs/workflow/merge.md`.
- **Devops** — test-merges when other pull requests are open, then verifies live. See `docs/workflow/merge.md`.
- **Map** — a `MAP.md`: one line per entry (path, what it answers, when to read it). See `docs/meta/layout.md`.
