# Impact

A pull request, a handoff, and an audit report open with Impact. The point is feature review.

## Impact

Before: what the user experienced.
After: what the user experiences now.
Load time: milliseconds, or unchanged.
Steps: how many steps to finish the task.
Errors: what the user hits, or none.

Write a number only when you measured it. Otherwise write "not measured".

Do not put lines, files, or coverage in Impact.

Use as few words as you can. Checks, the handoff, and findings come after Impact.
