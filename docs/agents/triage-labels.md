# Triage labels

| Label             | Meaning                                                 |
| ----------------- | ------------------------------------------------------- |
| `needs-triage`    | New, not yet assessed                                   |
| `needs-info`      | Blocked on a question to a human                        |
| `ready-for-agent` | Specified well enough for an agent to build             |
| `ready-for-human` | Needs a human (judgement, credentials, design sign-off) |
| `wontfix`         | Closed without action, with a reason                    |
