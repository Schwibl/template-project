# Code comments

No code comments.

Allowed only:

- A tool directive that carries a reason, such as `eslint-disable-next-line eqeqeq -- fixture uses ==` or `@ts-expect-error legacy types omit this field`.
- A license header (`Copyright`, `SPDX-License-Identifier`, or `License` before any code).
- A generated file (`@generated`, `DO NOT EDIT`, or `Code generated by` in the first 30 lines).

The allowed set is: tool directives that carry a reason, license headers, and generated files.

`npm run lint` runs `scripts/comments.ts` on JS, TS, Vue, CSS, HTML comments, YAML, and `.env.example`.

`.env.example` lists keys and sample values with no comments. Explain a key in the README.

The Ponytail import in `AGENTS.md` follows this rule.
