# Map

Open the one file that answers the question, then stop.

- `AGENTS.md` — triggers, repo facts, and Ponytail rules — at the start of every task
- `README.md` — what this template is and how to run it — when starting a project from it
- `CONTEXT.md` — names for Impact, Tech-lead, Devops, and Map — when a project term is unclear
- `THIRD_PARTY_NOTICES.md` — Ponytail MIT notice — when redistributing the Ponytail text
- `LICENSE` — MIT license for this repo — before copying the template
- `docs/MAP.md` — index of project docs — when the answer is a decision, workflow, or tracker
- `.prompts/base/MAP.md` — cook, git, and document habits — before planning, branching, or writing docs
- `skills/MAP.md` — index of skills — when a skill trigger fires
- `agents/MAP.md` — index of roles — when acting as a named role
- `.github/PULL_REQUEST_TEMPLATE.md` — pull request body that opens with Impact — when opening a pull request
